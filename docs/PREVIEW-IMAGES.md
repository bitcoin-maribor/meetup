# Nekdanje vzorčne naslovne slike

**Zgodovinski seznam:** spodnje vzorčne slike so bile odstranjene iz map meetupov in zamenjane s slikami iz javnih objav skupine. Aktualni viri so v [meetup-sources.json](meetup-sources.json), navodila v [MEETUP-IMPORT.md](MEETUP-IMPORT.md).

Slike so bile namenjene predogledu izvorne postavitve Zolarwind. Niso fotografije meetupov in ne nadomeščajo manjkajočih prilog predstavitev.

Kopirane so iz lokalne teme Zolarwind. Licenca vzorčnih fotografij je ohranjena v `themes/zolarwind/static/img/LICENSE.txt`; izvirne navedbe avtorjev so v `docs/zolarwind-attributions.md`.

Vsak meetup je mapa `content/meetups/LLLLMM/` z `index.md` in `banner.webp`. Slika se nastavi z `image = "banner.webp"` pod `[extra]`. Za zamenjavo prepišite sliko ali spremenite ime v metapodatkih. Če sliko in nastavitev odstranite, tema uporabi svojo privzeto sliko.
